# 02. AI 기능 평가 및 앱 조작 에이전트 로드맵

## 1. 목적

현재 브레인덤프와 할 일 쪼개기는 프롬프트가 결과를 생성하는 단계에 있다.
다음 목표는 기능을 바로 복잡한 에이전트로 바꾸는 것이 아니라, 아래 순서로
측정 가능성과 실행 권한을 한 단계씩 늘리는 것이다.

1. 현재 프롬프트의 품질을 설명할 수 있는 평가 기준과 기준선을 만든다.
2. 같은 평가로 프롬프트·모델·출력 계약 변경의 개선 여부를 반복 검증한다.
3. 브레인덤프와 쪼개기를 앱 전용 단일 에이전트의 후보 생성 기능으로 재사용한다.
4. 에이전트에 조회와 미리보기 도구부터 연결한다.
5. 사용자 승인, 권한 검사, 감사 로그, 되돌리기를 갖춘 쓰기 도구를 하나씩 연다.
6. 공통 실행부와 도메인별 구성을 분리해 다른 생산성 주제로 확장한다.

이 문서는 개발자 1명이 AI 평가와 에이전트 구축을 처음 시작한다고 가정한다.
날짜보다 각 단계의 졸업 조건을 충족하는 것이 중요하다.

선행 문서는
[01. 에이전트 구축 전 대화형 AI 최소 API 발판 계획](./01-ai-api.md)이다.

여기서 “다른 생산성 주제로 확장한다.”는 Todo 중심 앱을 습관·공부 계획처럼 entity와
업무 규칙이 다른 제품 도메인으로 바꾸는 경우를 뜻한다.
